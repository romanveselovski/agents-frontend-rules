# Russian in articles

English in prose only if it is a brand, a UI label, or a term with no normal replacement.

## Prefer Russian in prose

| Avoid | Prefer |
|----------|--------|
| workflow / pipeline | процесс, сценарий |
| upload | загрузка |
| ecommerce | интернет-магазин |
| listing | объявление, карточка |
| DIY | своими силами |
| UX (for people) | интерфейс, как пользоваться |
| immersive | наглядный просмотр |
| SKU in a paragraph | артикул (if the product uses that) |
| URL in a paragraph | адрес, ссылка |

## Keep Latin

Brands, app stores, formats (WebP, PDF), API field names in code samples, the site domain.

Extend the list in [project-facts.md](project-facts.md) for your product.

## Check

Read title, description, every section and FAQ. Facts match the source language. Extra Latin in a Russian sentence — replace or allowlist on purpose.
