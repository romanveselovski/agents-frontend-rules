# blog-author

Universal rules for articles and blogs. Not tied to a product, CMS, country, or stack.

Put the folder in a project as `.cursor/skills/blog-author/` or keep it under `web-ai-rules/skills/blog-author/`. Invoke: `@blog-author` plus a draft.

UI code follows `../../rules/`. Copy also follows `avoid-ai-writing.mdc` and `52-copy.mdc`.

## Files

- `SKILL.md` — article pipeline
- `project-facts.md` — product facts (fill per site; template)
- `product-facts.md` — alias to the template
- `content-template.md` — article skeleton
- `copywriting.md` — clarity and honest claims
- `narrative-rewrite.md` — connected prose, not an outline
- `humanize.md` — AI-ism check
- `ru-locale-style.md` — Russian without extra anglicisms
- `image-style.md` — cover and inline images
- `examples.md` — how to invoke
- `skills/` — optional SEO skills (keywords, schema, audit)

Publish, sitemap, Indexing API live in the site repo, not here.
