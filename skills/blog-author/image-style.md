# Article images

## Sizes

- Cover and large inline: one size per project (often 1200×630 for OG or 1536×1024). `width`/`height` in markup are required.
- Put files in the site media folder (`public/blog/{slug}/` or equivalent). No leftover files in the article folder.

## Brand

Take logo, wordmark, and domain from [project-facts.md](project-facts.md) and existing site assets. Do not draw a “similar” mark. No third-party watermark.

If the image shows embed code — only the snippet from project docs, not an invented `init()`.

## Look

Neutral background, readable labels, a scene on topic. No neon, no fake screens of features that do not exist.

Alt describes the image. Cover usually matches OG.

## After generation

Check the logo by eye. Delete unused PNGs. Set `coverImageAlt`.
